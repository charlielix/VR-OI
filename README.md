# VR OI 考场 · 重制版

第一人称虚拟 NOI 考场。四小时、四道题、四百分；能写代码、能喝水、能去洗手间、能干扰同学偷看他的代码、
能举手喊老师 —— 也能一拳把监考老师放倒，然后被两百名保安追着打。

本项目是对同一玩法的**重写实现**：代码全部重写，架构、物理、判题、灯光与后处理都换了自己的做法，
并补了原版没有的校园段、多考场楼层、3D 走廊、教室门、电梯间等内容。版本沿革见下一节。

## 快速开始

**必须用 `http://` 或 `https://` 打开**，`file://` 下浏览器会拒绝加载资源、`localStorage` 也不可用。
`index.html` 内置了这条检查：用 `file://` 打开会直接给出可照抄的命令，不会留你对着白屏。

最省事的办法：

```bash
# 装了 Node 就能用，零依赖（推荐）
node tools/serve.mjs
```

或者双击根目录里的 `serve.cmd`（Windows）。然后浏览器打开：

```
http://127.0.0.1:8848/
```

判断标准：地址栏是 `http://` 或 `https://` 就对了，是 `file://` 就错了。

> 为什么推荐 `tools/serve.mjs` 而不是 `python -m http.server`：后者不发缓存头，浏览器会启用
> 启发式缓存，改了代码刷新后可能还在跑旧版本。`serve.mjs` 启动时算出源码 BUILD_ID，
> 自动把 `index.html` 里的 `?v=` 全部重写，改过任何文件 URL 就变，浏览器必然重新拉取。

`three.js` 由 `index.html` 里一个静态阻塞标签加载，默认走本地 `vendor/three.min.js`
（零网络依赖、离线可用）。丢了就把标签 `src` 换成注释里列出的任意 CDN 地址。

开始界面底部有一行很小的 `构建 xxxxxxxxxx`，用来一眼判断"浏览器是不是还在跑旧缓存"。

想用 https（比如从局域网其它设备访问）？`node tools/gencert.mjs` 自签证书 +
`node tools/serve-tls.mjs` 起 `https://127.0.0.1:8443/`，证书产物在 `certs/`（不入库）。

## 玩法

### 第一段：从校门口到 404

1. 出生在第 114 中学校门口的砖路上。
2. 校门旁有**传送光圈**，站上去按 `F` 直接瞬移到教学楼门口。
3. 楼门口挂着「404 教室 · 考场 39」，路边志愿者也会告诉你楼号与教室号。
4. 按 `E` **过安检**：手机被收走封存；安检通过后落到 **1F 南端电梯间**。
5. 自己沿走廊走到 404，门前按 `E` 开门走进去 —— 走进教室那一刻比赛正式开始。

> 校门内侧有自动售货机：按 `E` 刷卡。饭卡开局 ¥12，矿泉水 ¥2 / 辣条 ¥3 / 臭水 ¥4，
> 库存 3 / 2 / 2，全买齐要 ¥20，得取舍。
>
> **员工通道**（主楼东侧夹道尽头没上锁的铁门）可以不过安检直接进楼：手机保住、还能捡到扫把，
> 解锁「不正规入场」；代价是老师巡逻看见你玩手机会当场没收。
>
> **入场预留**：开考后前 30 分钟不算考试时间，进楼后时钟跳到 4:00:00；
> 超过 30 分钟按迟到扣时；开考 4 小时 30 分钟后仍未进楼按缺考结算。

### 第二段：考场里

- 走到座位按 `E` 打开桌面，文件夹 `CSP-S114514` 里是本局抽到的 4 道题，双击进评测环境。
- 同一文件夹里的 `dino.exe` 是断网小恐龙（玩它会记一笔「摸鱼选手」）。
- 题池共 12 道（难度 1–5），每局抽 4 道，每题满分 100。

**出门与追击**：考场可以随时出门，不申请许可老师会追出来；被追上记一次警告并押回座位，
累计 5 次触发时间锁定（成绩取消）。按 `H` 申请去洗手间则老师放行不追。

**多考场 / 楼层**：1F 走廊西边是你的 404、东边是 405/406，北头洗手间、南头楼梯间；
楼梯按 `F` 上 2F（501/502）。每个考场都有门，`E` 开/关，开了 10 秒自动关，关着会挡路。
别的考场坐的是外班同学，干扰他们是纯捣蛋；惹毛 3 次会招来那间考场的监考老师。

**老师的那一眼**：老师沿超椭圆路线巡逻，每圈约 3 秒会走近你座位；这时若开着桌面/手机/别人的电脑，
会被记警告，看手机会被直接没收。

**干扰同学**：站到同学旁按 `F`，每干扰一次他后续交卷整体推后比赛时长的 6%；干扰 3 次他会去告状，
趁他离开按 `E` 用他的电脑。

### 第三段：打架

1. 正面对准监考老师按左键 → 获得 3 格血 + 受击无敌，两名保安冲进来。
2. 每打倒一名保安补两名，一局最多 200 名。
3. 打满 200 名后走廊尽头那扇门打开，走进白光触发隐藏结局「一人军队」。
4. 保安抓到扣 1 格血；血空了会被打倒，但比赛不会因此直接结束。

保安会追出教室、追进走廊 —— 开门跑出去也甩不掉，只能靠疾跑拉开距离；不过走廊里照样能出拳/抡武器。

### 物品与武器

| 物品 | 数量 | 效果 |
| --- | --- | --- |
| 臭水 | ×3 | 落点 2.6 米内保安干呕 2.6 秒，期间不追不抓不扣血 |
| 矿泉水 | ×2 | 回 1 格血（需先有血条） |
| 辣条 | ×2 | 6 秒内疾走 +35% |
| 手机 | ×1 | 过安检被收走；走员工通道可带进考场 |

武器不占快捷栏，左键永远是它，`Q` 永远是消耗品。空手拳锋 2.2m / 半角 0.40。

| 武器 | 拳锋 | 半角 | 耐久 | 获取 |
| --- | --- | --- | --- | --- |
| 扫把 | 3.3 m | 0.55 | 14 下 | 只有走员工通道才拿得到 |
| 拖把 | 3.6 m | 0.45 | 10 下 | 考场后墙角落固定补给点 |
| 板凳 | 2.9 m | 0.75 | 22 下 | 窗边固定补给点 |

地上补给走近 0.75 米自动捡起；战斗掉落固定节奏：每 3 杀掉臭水、每 5 杀掉矿泉水。

### 判题

浏览器里不编译不跑数据，用可解释、可复现的启发式评分（同一份代码反复提交分数一致）：

| 维度 | 分值 |
| --- | --- |
| 关键字密度 | 0–40 |
| 代码长度 | 0–30 |
| 结构完整度（main / 输入 / 输出 / return 0） | 0–30 |
| 算法进阶（二分、前缀和、记忆化、并查集、堆、取模等） | 0–10 |
| 确定性抖动（以代码 + 题目 id 作种子） | ±10 |

合计钳到 100 后映射到 10 个测试点；低于 10 分 WA，满分 AC，缺 `int main(` 或过短 CE；
出现屏蔽词直接取消本场成绩。界面右侧可看各维度得分明细。

### 名次与结算

考场里另外 5 名选手按各自节奏交卷，榜单实时变化（小刚抢交、小红终盘最高）。
干扰会真的推后他们的交卷时刻、拉低名次。

| 结果 | 触发条件 |
| --- | --- |
| 比赛结束 | 手动交卷 / 4 小时比赛时钟走完 |
| 缺考 | 开考 4 小时 30 分钟后仍未入场 |
| 成绩已取消 | 五次擅自离场被抓，或提交带屏蔽词的代码 |
| 一人军队 | 打满 200 名保安后走进走廊尽头白光 |

## 设置

开始界面与暂停菜单里可调（自动存 `localStorage`）：

- 鼠标灵敏度、视角平滑、音量、音效、镜头晃动
- 时间流速 1x–60x（只影响比赛时钟与世界逻辑，不影响操作）
- 保安速度（相对疾跑速度的比例，默认 90%，略慢于疾跑）
- 保安刷新位置（随机 / 门前 / 电梯间）
- 战斗光影（关掉后紧张值带来的灯光压暗、红光雾、调色、暗角、拖影全部复位，画面保持平时亮度）

## 技术栈

- **three.js r128**，纯前端零构建，传统 `<script>` 全局作用域，本地 `vendor/three.min.js` 兜底。
- **区域切换**：校园 / 404 / 楼内走廊是坐标错开的独立空间，切换只换「移动边界 + 障碍表」，
  几何体永不销毁。
- **碰撞**：全局 AABB 障碍表，玩家 / 保安 / 老师共用。
- **后处理**：自研三通道 ping-pong 拖影（不用 `EffectComposer`），blit 里显式 linear→sRGB。
- **判题**：纯前端确定性启发式，可复现。
- **存档**：`localStorage`，含安检/手机/背包/设置等状态。

### 验证

项目自带三层校验：

```bash
node tools/tdzscan.mjs        # 跨文件暂时性死区 / 重复声明静态扫描
node tools/smoke.mjs          # 无头 vm 冒烟测试（逻辑断言 + THREE 桩覆盖自检）
node tools/browsercheck.mjs http://127.0.0.1:8848/index.html "<chrome路径>"   # CDP 真 Chrome
```

`smoke.mjs` 覆盖判题、校园、安检、手机、保安刷点、战斗、存档等；`browsercheck.mjs` 在真实浏览器里
跑启动 / 渲染 / 提交评测 / 弹窗 / 战斗 / 结算。改动后三层都应为绿。
